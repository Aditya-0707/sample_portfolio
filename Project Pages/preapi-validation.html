Case Study

BRMS Request Validator
Pre-API Analysis Tool

A web-based solution designed to perform pre-validation of complex BRMS JSON requests, enabling early detection of errors before API execution and ensuring consistency across deployments.

Enabled proactive validation of business rules and JSON structures, significantly improving system reliability during both operations and releases.

Business Analysis Google Sheets Google Apps Script BRMS JSON Validation
The Core Challenge

Post-API Detection Failures

🚨 The Problem

In a complex BRMS-driven insurance system (500+ validation rules), JSON-based API requests were directly sent to the system for validation.

  • Errors detected only after API execution
  • High failed requests increased system load & cost
  • L1 teams struggled with slow troubleshooting
  • Deployments often broke JSON structures
  • No standardized way to pre-validate payloads
💡 The Solution

Proposed and implemented a pre-analysis interface allowing users to validate large JSON requests before they ever hit the API.

  • Instant pre-validation across 500+ rule conditions
  • Errors & missing values highlighted immediately
  • JSON structures verified before deployments
  • Only valid, clean requests are sent to the API
  • Drastic reduction in unnecessary API calls
Transformation

Before vs After Workflow

Shifting validation left — moving from a reactive, post-API failure model to a proactive, pre-API analysis model.

5

✅ New Workflow (Proactive)
