Overview

Continuous Health Monitoring, Zero Human Dependency

PulseGuard is a backend-driven automation framework designed to eliminate manual sanity checks and ensure continuous system health monitoring across critical environments. The tool replicates real-user interactions and backend validations by combining Python automation, Selenium-based browser testing, and Google Apps Script (GAS) for API monitoring and reporting. It performs scheduled sanity checks across Production and UAT environments, validating system readiness, login performance, portal responsiveness, and API health — all without human intervention.

How It Works

The Monitoring Flow

PulseGuard orchestrates a multi-layered validation cycle that runs autonomously across environments — from triggering scheduled checks to delivering actionable reports.

01

Scheduled Trigger

Task Scheduler / Cron initiates the sanity check cycle at configured intervals — every 3 hours for production, with additional cycles for UAT environments.

02

UI Validation via Selenium

Python + Selenium scripts launch browser sessions, verify server availability, simulate real user login flows, and validate that login completes within the ≤ 5 second threshold.

03

Portal & Component Testing

The engine opens multiple portals, pop-ups, and work items — measuring individual load times for each component and flagging any latency breaches automatically.

04

API Health Check via GAS

Google Apps Script validates all critical APIs against strict SLA thresholds — main APIs must respond within ≤ 3 seconds, individual APIs within ≤ 1 second.

05

Report Generation & Alerting

Concise health reports are auto-generated and sent directly to Microsoft Teams. Any threshold breach triggers intelligent real-time alerts for immediate action.
