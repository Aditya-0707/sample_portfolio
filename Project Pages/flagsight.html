The Challenge

Critical Flags, Manual Bottlenecks

In the insurance new business workflow, multiple dependent APIs (8+ services) are responsible for generating critical decision flags (CRC/PIVC). Due to intermittent system issues, incorrect flags were being triggered across hundreds of production cases.

⚠️

600+ Urgent Cases

A massive backlog of production cases required urgent validation to ensure business continuity and compliance.

🖥️

Tedious Manual Process

Validation required logging into remote servers, querying databases, extracting JSON responses, and manually cross-checking flags.

❌

Error-Prone & Unscalable

The manual process took ~1 minute per case. For 600+ cases, that meant ~10+ hours of continuous, exhausting, and error-prone human effort per cycle.

10+ hrs
Per Validation Cycle
1 minute per case × 600+ cases manually checked
Key Capabilities

Intelligent Validation Pipeline

I designed and developed a web-based automation tool that completely streamlined the entire validation pipeline, moving from manual server checks to bulk UI processing.

🖱️

Bulk UI Input

Input hundreds of case IDs directly via a clean, web-based UI rather than interacting with raw database queries.

🗄️

Automated Extraction

Automated database connection and seamless data extraction across the required dependent API services.

🧠

Intelligent Parsing

Automatic parsing of complex API response JSONs to locate and isolate the critical decision flags.

✅

Logic Validation

Validation of CRC/PIVC flags based on predefined business logic, flagging any inconsistencies immediately.

⚡

Batch Processing

Built to handle bulk processing of 600+ production cases simultaneously without timeouts or memory issues.

📄

Audit Reports

Auto-generation of structured, client-ready reports detailing the validation outcomes for every processed case.
